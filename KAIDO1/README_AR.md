# KAIDO × NOVA — النسخة المطوّرة

تطوير جديد مبني على آخر نسخة من KAIDO1، مع إزالة الواتساب بالكامل من الواجهة والكود وروابط المساعد ورقم الهاتف. الحزمة تشمل الملف الجاهز للفتح، والمصدر القابل للتعديل، والصور المحسّنة ووظائف الإدارة.

## ما تغيّر

- مشهد ثلاثي الأبعاد مرسوم برمجيًا بثلاثة أشكال: «عقدة»، «مدار»، «موجة». التحوّل يبدأ من الشكل الظاهر، حتى لو بدّلت الاختيار بسرعة. اضغط شعار NOVA أو استخدم Enter/Space لتبديل الجليدي والذهبي.
- دخول بحروف مقنّعة للعناوين، وتدرّج للواجهة والمشهد، وانتقال بين الفنانين بستارتين ضوئيتين ينتهيان عند جاهزية الصفحة الفعلية.
- طبقات عمق وإضاءة، وحدود تتبع المؤشر، وميل هادئ للبطاقات، وحلقات تشغيل وتفاصيل ضغط للأزرار. يتحرك مؤشر التبويبات بين الاختيارات.
- فواصل مرقّمة للأقسام، ومؤشر لتقدّم التمرير الحقيقي، وتنقل جانبي على الشاشات الكبيرة. روابط الأقسام تعمل داخل الصفحة المضمّنة.
- بطاقة افتتاحية بتوزيع تحريري، وترقيم للأعمال، وعدّادات مستمدّة من المحتوى الفعلي، وحالات واضحة عندما يكون القسم فارغًا.
- قسم تعاون جديد؛ إنستغرام هو إجراء التواصل الأساسي. منصات الموسيقى والحسابات الأصلية محفوظة، وأزيلت خدمة الواتساب ورقمها وأيقوناتها ووظائفها تمامًا.
- المشهد يحترم زر الحركة وإعداد الجهاز، ويتوقف خارج الشاشة وعند إخفاء التبويب. تفاصيل ودقة أقل على الهاتف والأجهزة الأضعف. لا توجد مكتبات تشغيل إضافية.
- 39 إدخالًا في قوائم الأعمال محفوظة؛ تشغيل الفيديو والبحث والتنقل بالكيبورد ولوحة الإدارة ووظائف الخادم محفوظة.
- الصور المضمّنة نحو 1.14 MB بدل 8.86 MB؛ كل ملف واجهة نحو 2.18 MB بدل 12.77 MB في الأصل.

## فتح ومعاينة الملف

فك ضغط `KAIDO1.zip` ثم افتح `KAIDO1/index.html` بمتصفح حديث يدعم DecompressionStream. واجهة الصفحة ومشهدها ورسوماتها مضمّنة؛ تحميل الخطوط ومعاينات يوتيوب وتشغيل الفيديو يحتاج اتصالًا بالإنترنت. لوحة الإدارة تحتاج النشر وإعداد الخادم كما هو موضح أدناه.

للتعديل، افتح ملفات `source/pages/kaido.html` و`source/pages/nova.html`. الصور المشار إليها برموز `__KN_MEDIA:...__` موجودة في `source/media` مع خريطتها `source/media.json`. ملفات الحركة والمظهر في `motion`، وقالبا النافذة الرئيسية في `source/shell-local.html` و`source/shell-hosted.html`.

شغّل الأوامر من المجلد الذي يحتوي `package.json`:

```sh
npm run build
npm test
npm run check:frontend
```

البناء يعيد توليد `index.html` و`public/index.html` وينسخ `youtube-player.html` إلى `public`. عدّل المصدر ثم أعد البناء؛ التعديل المباشر على الواجهة الناتجة يضيع عند إعادة بنائها. الاختبارات لا تحتاج تثبيت حزم إضافية.

## حدود الفحص والفحص البصري المطلوب

نجحت اختبارات البناء ووظائف الخادم والحركة والتحميل، وفحص صياغة السكربتات الفعلية وتحويل بيانات الأعمال. تعذّرت المعاينة البصرية داخل متصفح هذه الجلسة؛ لذلك لا تُعدّ هذه النتائج فحصًا بصريًا كاملًا أو تجربة نشر حيّة على Vercel/Upstash.

بعد فتح الموقع جرّب عرض الهاتف 320 و390 بكسل والكمبيوتر، الانتقال بين KAIDO وNOVA، أزرار المشهد وشعار NOVA، التبويبات والبحث وتشغيل الفيديو، وإغلاق النوافذ ثم متابعة التنقل بالكيبورد. فعّل إعداد تقليل الحركة في جهازك وجرّب زر الحركة والانتقال بين الفنانين. إعدادات الإدارة والنشر الأصلية أدناه.

# إصلاح لوحة إدارة KAIDO × NOVA على Vercel

هذه حزمة مشروع كاملة بدل رفع ملف HTML وحده. الموقع الأصلي وصوره وأقسامه محفوظة داخل public/index.html، ومعها خمس وظائف API وخزن دائم في Upstash Redis.

## لماذا ظهرت الرسالة؟

طلب https://kaido-1.vercel.app/api/session رجع HTTP 404 أثناء الفحص بتاريخ 20 سبتمبر 2026. صفحة الإدارة تستدعي هذا المسار ومسارات أخرى غير موجودة في ملف HTML وحده. الحزمة تضيف هذه المسارات؛ يبقى إعداد قاعدة البيانات ومتغيرات البيئة ثم نشر الحزمة في مشروعك.

## 1. ربط قاعدة البيانات

1. افتح مشروع kaido-1 في Vercel.
2. من Storage أو Marketplace اختر Upstash Redis وأنشئ قاعدة أو اربط قاعدة موجودة بالمشروع. راجع الخطة المعروضة قبل اختيارها.
3. اربط القاعدة ببيئة Production. إذا تريد اختبار Preview، استخدم قاعدة منفصلة أو DATA_PREFIX مختلفًا حتى لا يعدّل الاختبار بيانات الموقع الحقيقي.
4. يلزم متغيرا UPSTASH_REDIS_REST_URL وUPSTASH_REDIS_REST_TOKEN. الحزمة تقبل أيضًا KV_REST_API_URL وKV_REST_API_TOKEN إذا التكامل أنشأهما بهذه الأسماء.
5. المطلوب رمز REST بصلاحية القراءة والكتابة، وليس READ_ONLY_TOKEN ولا رابط redis://.

## 2. إعداد حسابات الأدمن

افتح Settings → Environment Variables في مشروع Vercel، وأضف القيم التالية لبيئة Production. اكتب القيم بدون علامات اقتباس.

| اسم المتغير | القيمة |
|---|---|
| SITE_ORIGIN | https://kaido-1.vercel.app |
| UPSTASH_REDIS_REST_URL | رابط REST من قاعدة Upstash إن لم يضفه التكامل |
| UPSTASH_REDIS_REST_TOKEN | رمز REST الخاص بالقاعدة إن لم يضفه التكامل |
| KAIDO_PASSWORD | كلمة مرور تختارها لحساب kaido، من 12 حرفًا على الأقل |
| NOVA_PASSWORD | كلمة مرور مختلفة تختارها لحساب nova، من 12 حرفًا على الأقل |
| ADMIN_TOOL_CODE | رمز ثانٍ تختاره، من 8 أحرف على الأقل، يختلف عن كلمات المرور |
| DATA_PREFIX | kaido-nova:v1؛ اختياري، وهذه القيمة الافتراضية |

- لا تضع #kaido أو مسارًا إضافيًا ضمن SITE_ORIGIN.
- لا توجد كلمات مرور افتراضية. أنت تختارها داخل Vercel؛ لا ترسل كلمات المرور أو رمز قاعدة البيانات في المحادثة.
- رمز التوول هنا رمز ثابت إضافي وليس رمز تطبيق مصادقة متغيرًا مع الوقت.
- حسابا kaido وnova مسؤولان عن قوائم الفنانين كليهما، حفاظًا على سلوك اللوحة الأصلية. لم نضف عزل صلاحيات كل فنان عن الآخر.
- البيانات السرية موجودة بالخادم فقط، وليست داخل HTML. تغيير كلمات المرور أو رمز التوول ثم إعادة النشر يُبطل الجلسات القديمة.
- لا تغير DATA_PREFIX بعد الاستخدام إلا إذا أردت مجموعة بيانات مستقلة؛ إبقاؤه ثابتًا يحافظ على القوائم عبر النشرات.

## 3. رفع المشروع الكامل

### إذا مشروع Vercel مربوط بـGitHub

1. فك ضغط KAIDO1.zip على جهازك.
2. افتح مستودع GitHub المربوط بمشروع kaido-1.
3. ارفع محتويات الحزمة إلى جذر المشروع: api وlib وpublic وscripts وpackage.json وvercel.json. لا ترفع ملف ZIP نفسه، ولا تضع الملفات داخل مجلد إضافي تحت جذر المشروع.
4. استبدل vercel.json القديم بهذه النسخة. لا تستخدم تحويلًا عامًا يرسل /api/* إلى index.html.
5. نفّذ Commit للتغييرات ليبدأ نشر Vercel. لا ترفع ملفات .env تحتوي أسرارك.

### إعدادات البناء في Vercel

من Settings → Build and Deployment تأكد من:

| الإعداد | القيمة |
|---|---|
| Framework Preset | Other |
| Root Directory | المجلد الذي يحتوي package.json وapi وpublic؛ جذر المستودع إذا رفعت المحتويات هناك |
| Build Command | npm run build |
| Output Directory | public |
| Node.js Version | 24.x |

الملف vercel.json يحدد أمر البناء ومجلد الإخراج. لا تختَر public باعتباره Root Directory؛ يجب أن ترى Vercel مجلدي api وlib أيضًا.

بعد إضافة متغيرات البيئة، افتح Deployments وأعد النشر (Redeploy) لأحدث نسخة. المتغيرات الجديدة لا تدخل حيّز العمل على نسخة منشورة سابقًا حتى تعيد نشرها.

إذا كنت تستخدم Vercel CLI بدل GitHub، شغّل vercel من مجلد الحزمة واربطها بالمشروع الحالي kaido-1، ثم انشر Preview للاختبار أو vercel --prod للنشر العام. ملفات الحزمة لا تنشر نفسها تلقائيًا.

## 4. التأكد من الحل

1. افتح https://kaido-1.vercel.app/api/session . بعد اكتمال الإعداد تظهر استجابة JSON مثل {"csrf":null,"pending":false} بدل 404.
2. افتح https://kaido-1.vercel.app/api/content . يفترض أن تظهر قوائم KAIDO وNOVA.
3. افتح الموقع واضغط تسجيل الدخول.
4. أدخل kaido وكلمة KAIDO_PASSWORD التي اخترتها، أو nova وكلمة NOVA_PASSWORD.
5. أدخل ADMIN_TOOL_CODE في حقل رمز التوول.
6. اختر الفنان ثم القسم وأضف رابط يوتيوب. افتح نافذة خاصة أو جهازًا آخر وتأكد من ظهوره؛ الزائر الذي أبقى الصفحة مفتوحة يحتاج تحديث الصفحة لرؤية تغييرات جديدة.
7. جرّب حذف الإضافة ثم تحديث الصفحة للتأكد من حفظ الحذف.

القوائم تبدأ بالفيديوهات الـ39 الموجودة في ملفك. التهيئة تحصل فقط للقوائم غير الموجودة، ولا تستبدل قوائم محفوظة، حتى لو حذفت جميع فيديوهات قسم.

## ماذا تشمل اللوحة؟

- KAIDO: أعمالي، الدسات، الإعلانات.
- NOVA: من أجمل التراكات، أعمال الفيديو، الهندسة الصوتية.
- إضافة وحذف روابط يوتيوب، مع منع تكرار نفس الفيديو داخل القسم.
- لا تشمل رفع ملفات فيديو محلية أو تعديل الصور والنصوص والعناوين.
- حد كل قسم 500 فيديو؛ الجلسة 8 ساعات، ومهلة إدخال رمز التوول 5 دقائق.
- حماية جلسة بملفات ارتباط HttpOnly وSecure وSameSite، وفحص مصدر الطلب ورمز CSRF.
- تقييد محاولات الدخول والتحقق. عند ظهور رسالة محاولات كثيرة، انتظر 15 دقيقة.
- عمليات تعديل القائمة تتم ذريًا في Redis لتقليل تعارض التعديلات المتزامنة.

## إذا ظهر خطأ

| العرض | الحل |
|---|---|
| /api/session يرجع 404 | مجلد api لم يُرفع أو Root Directory غير صحيح أو نُشرت نسخة قديمة أو توجد قاعدة تحويل قديمة |
| رسالة قاعدة البيانات غير مربوطة | تحقق من متغيري REST ومن ربط Production ثم Redeploy |
| رسالة أكمل إعداد كلمات المرور | أكمل المتغيرات الثلاثة والأطوال المطلوبة ثم Redeploy |
| طلب غير مسموح | افتح https://kaido-1.vercel.app وتأكد أن SITE_ORIGIN يساوي هذا الأصل. رابط Preview يحتاج SITE_ORIGIN خاصًا به |
| انتهت الجلسة | أغلق لوحة الإدارة وافتحها وسجّل الدخول مجددًا |
| الموقع يعرض أعماله لكن الأدمن لا يعمل | العرض يستطيع استخدام القوائم المدمجة عند تعطل API؛ افحص /api/session و/api/content مباشرة |

## التحقق المنفذ وحدوده

- اختبارات آلية لمنطق الدخول والتحقق، الحفظ والحذف، الجلسات، منع الطلبات غير المصرح بها، تقييد المحاولات وروابط يوتيوب.
- الاختبارات المحلية تستخدم محاكاة Redis REST ولا تثبت اتصالًا بحساب Upstash حقيقي.
- سكربتات الواجهة فُحصت نحويًا. تفاصيل فحص المتصفح في TEST_RESULTS.txt.
- لم يُنشر هذا الإصلاح في حساب Vercel الخاص بك من هذه المحادثة. يلزم رفع الحزمة وإعداد المتغيرات والقاعدة لاختبارها على الاستضافة الحقيقية.
