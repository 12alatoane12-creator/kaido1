# KAIDO1 — cinematic motion refinement

The user requests a major refinement of the latest delivered ZIP, beginning with complete removal of WhatsApp. Work starts from the latest package, in an isolated directory; the prior delivery stays available until this package is verified.

## Binding requirements

- Remove every WhatsApp control, floating icon, service URL, telephone number, CSS rule, helper and assistant reference from the emitted site.
- Keep the artist identities, original artwork, all 39 seeded catalogue entries, existing social accounts, video player, administration and backend contracts. Contact now starts with the existing Instagram account.
- Improve entrance, hover, 3D motion, parallax, microinteractions and page transitions as one consistent visual language.
- Keep the local and hosted entries self-contained, each below 2.7 MB. Add no runtime dependencies.
- Every animation respects the shared user/OS motion policy, document visibility and scene intersection. Small devices use bounded geometry and pixel density. Loading reports real readiness, without a fabricated percentage or minimum delay.

## Direction

Warm metal and restrained violet light for KAIDO; cool silver-blue for NOVA. A larger sculptural wire form surrounds the original logo, with three directly selectable forms: knot, orbit and wave. Form changes interpolate the same mesh and preserve continuity when changed again midway. Depth shading, a floor projection and sparse highlights give volume without downloaded models.

Headlines enter through clipped letter masks; Arabic stays in complete glyph sequences. Two light curtains reveal the actual ready page. The introduction layers typography, scene and small metadata with staggered timing. Scroll movement is limited to decorative layers.

Numbered section dividers, an actual scroll progress line and a desktop section rail make the long catalogue easier to navigate. The first music card receives an editorial layout. Card images decode into a quiet preview, borders follow the pointer, and controls have small press/arrow responses. Tab selection has a moving marker; the tab and dialog keyboard contracts remain intact.

Contact becomes a clear artist collaboration panel, with Instagram as the primary action and the original music/social platforms below. No contact number is retained.

- [Microinteraction](https://dribbble.com/search/microinteraction): tab markers, compact control feedback and progressive focus.

These are design references, not copied assets or code. Browser inspection of the local build is restricted in this environment; automated runtime checks and source checks cannot certify its final visual appearance.
